# JHC 商赛：消费者洞察与商业假设

**时间：2024.03 - 2024.05**  
**本人角色：市场分析与英文路演**  
**团队结果：广州赛区第三名**

## 项目问题

围绕绿色能源与双碳 ESG 转型商业案例，分析消费者的低碳消费诉求及支付意愿，为目标市场选择和推广方案提供依据。

## 本人贡献

- 分析 300 余份消费者调研样本，梳理低碳消费诉求与支付意愿。
- 参与识别愿为低碳供应链支付 15% 溢价的核心客群，支持目标市场判断。
- 参与营销投入产出测算，将推广投入与预期回报转化为商业假设。
- 负责市场分析板块的全英文路演和现场答辩，整合消费者研究、客群画像与测算结论。

## 结果口径

| 项目 | 含义 |
| --- | --- |
| 300 余份样本 | 商赛中的消费者调研分析基础 |
| 15% 溢价 | 调研中识别的目标客群支付意愿，不代表已实现售价 |
| 1∶4.5 | 方案预期投入产出比，属于模型测算，不是实际经营收益 |
| 广州赛区第三名 | 团队获得的比赛成绩 |

## 对项目判断的启发

调研能够帮助提出方向，但问卷中的支付意愿仍需要真实行为验证。商业模型可以说明假设之间的关系，不能代替实际收入、留存和成本数据。

如进一步落地，我会先缩小目标客群，明确最关键的需求假设，再通过访谈、小规模测试和实际选择行为验证，之后调整资源投入。这是后续验证思路，不是已经完成的商业试验。
