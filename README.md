## 怎么阅读这些案例

每篇案例分别说明实际经历、本人贡献、已有结果及后续验证思路。案例复盘与提示词示例属于文档作品，目前没有提供已上线的独立 AI 产品，也没有将模拟样例计为真实用户反馈或业务成果。

本仓库未收录企业合同、客户资料、交易流水、实习内部文件或个人联系方式。公开提示词及模拟输入为本次作品集整理时新增的示例，由 Codex 辅助起草；它们不代表历史工作原件，也没有在本仓库中调用模型或连接企业系统。
